# Сервис портфолио студентов

## Назначение
Приложение для управления академическими и профессиональными достижениями студентов.
Консольная версия (ПР3) дополнена веб-интерфейсом на Django (ПР5).

## Используемые технологии
- Python 3.11 / 3.13
- Django 5.2.* 
- HTML5, CSS3, Bootstrap 5.3
- pytest
- flake8

## Структура веб-приложений
- `homepage/` — главная страница (`/`), навигация и базовый HTML-каркас (`page()`), собственный обработчик ошибки 404 (`page_not_found`).
- `students/` — список студентов (`/students/`) и страница студента (`/students/<id>/`).
- `projects/` — список проектов (`/projects/`) и страница проекта (`/projects/<id>/`).
- `achievements/` — список достижений (`/achievements/`) и карточка достижения с подтверждающим документом (`/achievements/<id>/`).

## Хранение данных
Данные хранятся в JSON-файлах в каталоге `data/`:
- `students.json`
- `projects.json`
- `achievements.json`
- `documents.json`
