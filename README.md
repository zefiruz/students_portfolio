# Сервис портфолио студентов
Консольное приложение для управления академическими и профессиональными достижениями студентов.

## Назначение
Хранение и демонстрация достижений, учебных проектов, навыков и подтверждающих документов студентов для потенциальных работодателей и преподавателей.

## Целевая аудитория
Студенты, преподаватели, HR-специалисты, работодатели.

## Предметная область
Образование, карьера, учет академических и профессиональных достижений. Объекты Проект (Project), Достижение (Achievement) и Документ (Document) неразрывно связаны с основным объектом Студента (Student).

## Основные сущности (Классы)
* **Student** 
  * Атрибуты: id, name, gpa, skills
  * Методы: check_profile_completion(), calculate_rating(projects_count)
* **Project**
  * Атрибуты: id, title, status, student (ссылка на объект Student)
  * Методы: get_status_info(), update_status(new_status)
* **Achievement**
  * Атрибуты: id, title, issue_date, category, student (ссылка на объект Student)
  * Методы: is_recent(current_year)
* **Document**
  * Атрибуты: id, title, file_path, owner (ссылка на объект Student)
  * Свойства: extension (вычисляемое свойство `@property` для определения формата файла)

## Основные функции
1. Проверка полноты заполнения профиля студента.
2. Определение и изменение статуса учебных проектов.
3. Расчет предварительного рейтинга студента на основе количества проектов и среднего балла.
4. Учет дополнительных академических и профессиональных достижений (хакатоны, олимпиады, сертификаты).
5. Прикрепление электронных документов с автоматическим определением их формата (расширения).

## Структура проекта
* `models/` — пакет с классами предметной области (`student.py`, `project.py`, `achievement.py`, `document.py`).
* `storage.py` — сохранение и загрузка данных в JSON с поддержкой восстановления связей между объектами.
* `utils.py` — функции защиты от некорректного пользовательского ввода.
* `main.py` — точка входа и консольный интерфейс.
* `tests/` — автоматизированные тесты pytest.
* `data/` — директория для хранения JSON-файлов данных (`students.json`, `projects.json`, `achievements.json`, `documents.json`).
