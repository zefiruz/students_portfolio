# Сервис портфолио студентов
Консольное приложение для управления академическими и профессиональными достижениями студентов.

## Назначение
Хранение и демонстрация достижений, учебных проектов и навыков студентов для потенциальных работодателей и преподавателей.

## Целевая аудитория
Студенты, преподаватели, HR-специалисты, работодатели.

## Предметная область
Образование, карьера, учет академических и профессиональных достижений. Объект Проект (Project) неразрывно связан с объектом Студента (Student).

## Основные сущности (Классы)
* **Student** 
  * Атрибуты: id, name, gpa, skills
  * Методы: check_profile_completion(), calculate_rating(projects_count)
* **Project**
  * Атрибуты: id, title, status, student (ссылка на объект Student)
  * Методы: get_status_info(), update_status(new_status)

## Основные функции
1. Проверка полноты заполнения профиля студента.
2. Определение текущего статуса проекта.
3. Расчет предварительного рейтинга студента на основе количества проектов и среднего балла.

## Структура проекта
* `models/` — классы предметной области.
* `storage.py` — сохранение/загрузка данных в JSON.
* `utils.py` — функции защиты от неверного ввода.
* `main.py` — интерфейс.
* `tests/` — автотесты pytest.
* `data/` — JSON файлы данных.

## План развития
На следующих этапах планируется:
* разработка веб-приложения на Django;
* подключение реляционной базы данных;
* реализация пользователей и аутентификации;
* разработка API.
